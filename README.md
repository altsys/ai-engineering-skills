# AI Engineering Skills

An executable curriculum for learning AI engineering with an AI assistant.

This repository is not a tutorial and not an "awesome list." Its skills teach by guiding learners through strong external resources, asking questions, assigning experiments, checking understanding, and adapting the path to the learner.

## Core idea

The AI should not replace the best books, papers, courses, documentation, or projects. It should help the learner use them well.

A skill should:

- diagnose what the learner already knows
- choose the next useful concept
- assign a specific external resource for a specific reason
- tell the learner what to pay attention to
- discuss the resource after they use it
- test understanding with questions and small builds
- identify misconceptions
- adapt difficulty and sequencing
- move on only when the learner can demonstrate understanding

## What this is not

It is not a generated textbook.

It is not a fixed course that assumes every learner starts from the same place.

It is not a large directory of links with no opinion about which resource to use.

## Design principle

**Teach by interaction. Learn by doing. Use the best source for the job.**

The long-term goal is a set of portable skills that can run in AI assistants and act as an adaptive AI engineering school.
