# Resource Schema

Every recommended resource should earn its place in the curriculum.

Use this structure when adding resources.

```yaml
title:
type: book | paper | docs | course | video | article | repository
url:
author:
topics:
level: beginner | intermediate | advanced
use_for:
why_this_resource:
specific_sections:
focus_on:
skip_for_now:
prerequisites:
follow_up_exercise:
alternatives:
```

## Rules

- Do not add a resource just because it is popular.
- Prefer a specific chapter, section, lecture, or exercise over assigning an entire resource.
- Say what the learner should extract from it.
- Say what can safely be skipped for the current lesson.
- Pair passive consumption with an active follow-up.
- Avoid duplicating resources that teach the same thing unless the alternative has a clear advantage.
