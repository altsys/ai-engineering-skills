# Resource Catalog

This catalog is intentionally small. Add resources only when they serve a clear teaching purpose.

## AI Engineering from Scratch

Status: backbone candidate

Use for:
- building practical intuition by implementing core AI engineering concepts
- connecting theory to code
- grounding lessons in small systems rather than abstract explanation

Guidance:
- assign specific sections or exercises, not the whole resource by default
- pair each assignment with a prediction, implementation, or debugging task
- use it when building from first principles improves understanding
- use official docs or papers instead when the learner needs authoritative API behavior or original research context
